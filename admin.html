Como criar o token
  1. No GitHub: foto do perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o repositório do site.
  3. Em Permissions → Repository permissions, mude Contents para Read and write. Nada mais.
  4. Gere, copie o token e cole aqui. Ele fica guardado só neste aparelho, protegido pela senha da administração.
